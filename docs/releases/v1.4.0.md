# AXON 1.4.0

Esta versión reúne gestión de discos y sesiones, organización de archivos, mejoras de Biblioteca y navegación móvil, junto con las correcciones pendientes del inventario de software y el lector de documentos.

## Cambios

- **Biblioteca:** botón visible para agregar carpetas de cualquier disco accesible mediante el explorador del servidor. La incorporación conserva las fuentes existentes, evita duplicados y valida la carpeta antes de indexarla. Los originales permanecen en su ubicación.
- **Navegación:** se retira el panel permanente de discos de Biblioteca, Agentes y Drops. Los discos siguen disponibles desde sus controles de exploración. El menú de Biblioteca en móvil tiene cierre al seleccionar, fondo para descartarlo, estado accesible, cierre con Escape y controles táctiles.
- **Vistas previas:** flechas visibles en Biblioteca también en móvil. Archivos incorpora anterior/siguiente, posición y límites, siguiendo el orden y los filtros actuales. Se puede recorrer el contenido sin cerrar el visor.
- **Archivos y carpetas:** colores, etiquetas, favoritos, guardados y accesos rápidos compartidos entre Archivos y Biblioteca, incluyendo carpetas vacías y búsqueda por organización. Cabeceras y transferencias compactas en móvil.
- **Documentos:** lector Markdown local con listas de tareas, tablas, bloques de código y modo explícito de lectura/edición. Conserva borradores al alternar y limpia los recursos al cerrar.
- **Discos:** administración de volúmenes con planificación, validación de identidad y confirmación de las operaciones, visibilidad de particiones técnicas y pruebas aisladas de seguridad.
- **Acceso:** API keys con permisos y límites visibles, consumo y control de revisiones. Inventario persistente de sesiones con cierre individual y cierre de las demás; revocación inmediata de streams autenticados.
- **Programas:** inventario progresivo, diagnósticos de instalaciones rotas, fuentes y candidatos de actualización sin bloquear la primera carga.
- **Compose:** detección de proyectos locales de Supabase y acciones de detención que conservan datos, junto con manejo de proyectos sin archivo Compose disponible.
- **Hardware opcional:** paneles de USB y ventiladores con adaptadores de host. Instalar o activar los servicios de hardware es una operación separada; actualizar AXON no instala esos servicios. El adaptador de ventiladores corresponde exclusivamente al modelo/firmware documentado.

## Validación

La publicación se verifica con TypeScript, sintaxis frontend, build, pruebas de aplicación y contratos Python de agentes, software, discos e instalador. El QA de navegador utiliza un servidor aislado y fixtures propias para las operaciones de escritura. CI incluye navegación, accesibilidad, temas y tamaños de pantalla, sesiones, USB y el flujo de carpetas/vistas previas.

La verificación de producción comprueba salud y revisión, paridad del código y los recursos, carga autenticada y navegación de escritorio/móvil. Las pruebas de recuperación o acciones de hardware no se ejecutan sobre datos personales como parte de la publicación.

## Actualización

Instalaciones administradas:

```bash
axon update --ref v1.4.0 --wait
axon status
```

Instalación nueva:

```bash
curl -fsSL https://raw.githubusercontent.com/LucasSabena/axon/v1.4.0/install.sh -o /tmp/axon-install.sh
bash /tmp/axon-install.sh --ref v1.4.0
```

Con Compose, conservá `.env` y `data/`, obtené esta versión y reconstruí únicamente AXON. El build genera nuevas huellas de los recursos y una versión del service worker para renovar la caché al recargar.

El despliegue conserva configuración, fuentes de Biblioteca, archivos y sesiones existentes. Guardá un respaldo antes de actualizar; `axon rollback --wait` en instalaciones administradas vuelve al código anterior conservando los datos actuales.
