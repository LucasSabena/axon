# AXON 1.3.0

## Cambios

- **Primer arranque:** el instalador imprime un enlace de primer acceso (`?setup=…`, de un solo uso) que abre el asistente de bienvenida: creás tu usuario y contraseña, AXON te muestra lo que detectó en el servidor (Docker, proyectos, discos) y elegís el tema. El inicio muestra "Primeros pasos" con ítems que se auto-completan desde el estado real y desaparece al terminarla. `axon reset-password` rota la credencial revocando sesiones; `axon reset-onboarding` reinicia la lista sin reabrir el setup.
- **Seguridad:** cambio de contraseña desde Configuración con verificación de la actual y revocación del resto de las sesiones; códigos de recuperación para 2FA; el proxy de puertos ya no reenvía `axon_session`/`Authorization` a servicios internos; validación estricta de dominios con rollback; sesiones de WebSocket revalidadas; masking reforzado de credenciales en MCP/config; denylist de archivos sensibles en Drop con expiración, contraseña y tope de descargas.
- **Interfaz:** PWA instalable (iconos 192/512/maskable), atajos ⌘K en las 24 secciones, empty states con explicación y CTAs en Puertos, Proyectos, Docker y Dominios, `crypto.randomUUID` con fallback fuera de contextos seguros, accesibilidad (skip-link, ARIA, teclado).
- **Archivos y Biblioteca:** detección de duplicados (size→sha1), subida de carpetas, filtros `tipo:`/`ext:`/`>100mb`, progreso y cancelación en movimientos, zip de carpeta, Tab-indent en el editor.
- **Compose:** preview de YAML real sin interpolar secretos, diff, timeout y cancelación de jobs.
- **Escritorio:** envío de texto al portapapeles remoto, Ctrl+Alt+Supr, solo ver, pantalla completa, resize de Xvfb, suspender/reanudar.
- **Plataforma:** SMART multi-disco, alertas con umbrales y tarjeta en Salud, auditoría con filtros/export/pruning, eliminación de cuentas de agentes, scripts con parámetros/env/cwd y timeout.
- **Instalación/CI:** imagen base fijada por digest, `HEALTHCHECK` sobre `/api/health`, `check-dist` verifica en build que todo worker referenciado se copie a `dist/`, yarn fijado a 4.18.1, setup-python en CI.

## Instalar o actualizar

Instalación nueva en Linux con Docker Engine, Compose 2.20+, Git y Python 3.10+:

```bash
curl -fsSL https://raw.githubusercontent.com/LucasSabena/axon/v1.3.0/install.sh -o /tmp/axon-install.sh
bash /tmp/axon-install.sh --ref v1.3.0
```

Instalaciones administradas existentes:

```bash
axon update --ref v1.3.0 --wait
axon status
```

El actualizador construye antes de detener AXON, respalda sus datos y comprueba la revisión nueva. Conserva login, configuración y cuentas. `axon rollback --wait` vuelve al código anterior manteniendo los datos actuales.

Instalaciones Compose: conservá `.env` y `data/`, obtené esta publicación y reconstruí únicamente AXON.

## Requisitos y alcance

Las instalaciones existentes (sin `onboarding.json`) no reciben el asistente: su configuración ya está hecha. El cambio de contraseña invalida las demás sesiones — el navegador donde la cambiás queda autenticado con la credencial nueva.
