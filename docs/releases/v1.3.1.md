# AXON 1.3.1

Esta publicación reúne las correcciones de la auditoría integral posterior a 1.3.0, con regresiones de autenticación, archivos, backups y ejecución de procesos.

## Correcciones

- **Login y seguridad:** doble verificación en un segundo paso únicamente después de validar la contraseña de una cuenta que la tenga activa. Admite TOTP y códigos de recuperación; la prueba pendiente vence, tiene límites de intentos y no crea una sesión antes de completarla. Rotación de credenciales y consumo de códigos de recuperación serializados; persistencia atómica y rechazo de estados de autenticación corruptos.
- **Backups:** ruta exacta y enlace a Archivos por destino, estado y etapas visibles, apertura del trabajo al hacer una copia, contadores de archivos/bytes mientras Restic corre y actualización del progreso que conserva el foco de teclado. Las copias con archivos ilegibles quedan claramente incompletas, permiten recuperar lo guardado y no ejecutan retención en ese trabajo. Volver a comprobarlas conserva la advertencia.
- **Archivos:** cálculo completo de tamaños en repositorios privados. Los errores de lectura ya no devuelven un subtotal como si fuera el total. Propiedades distingue tamaño de archivos y espacio ocupado en disco.
- **Biblioteca y uploads:** rollback de bloques interrumpidos al último offset confirmado, backpressure, cancelación que libera el escritor y finalización revalidada bajo bloqueo. Los reintentos no duplican bytes ni corrompen el archivo.
- **Procesos y solicitudes:** límites efectivos antes de parsear cuerpos HTTP, timeout de procesos de host también en desarrollo sin root y consultas Docker acotadas. Las lecturas SMART inconcluyentes conservan las alertas anteriores.
- **Consumo y accesibilidad:** tooltip próximo al puntero, que cambia de lado al acercarse a un borde y se oculta al navegar o desplazar. Contraste de Compose y de agentes sin instalar o con configuración residual, filtros accesibles de Historial y roles de Programas coherentes con estados vacíos.
- **Verificación:** TypeScript incluye los tests. QA utiliza dependencias locales y un servidor con fixtures propias; CI ejecuta navegación, login, autenticación, backups, consumo y contratos nativos. La versión informada por health en desarrollo sale de package.json.

## Validación

309 pruebas de aplicación, 2644 assertions, sin fallos; 145 comprobaciones de las 24 secciones, 6 escenarios de contraste de agentes con inventario independiente del host, 30 de navegación, login real con doble verificación, backups y recuperación selectiva con Restic real, prueba de copia incompleta recuperable y 16 posiciones del tooltip. Typecheck, sintaxis frontend y build aprobados.

Las correcciones funcionales se comprobaron además con lecturas en la instancia real, incluyendo el tamaño de DATOS, ubicación del repositorio, hover sobre consumo real y recarga de una sesión existente. Los tests de escritura y recuperación utilizan fixtures propias. Esto no certifica ausencia de bugs en cada función ni restauraciones de todos los datos personales.

## Instalar o actualizar

Instalación nueva en Linux con Docker Engine, Compose 2.20+, Git y Python 3.10+:

```bash
curl -fsSL https://raw.githubusercontent.com/LucasSabena/axon/v1.3.1/install.sh -o /tmp/axon-install.sh
bash /tmp/axon-install.sh --ref v1.3.1
```

Instalaciones administradas:

```bash
axon update --ref v1.3.1 --wait
axon status
```

El actualizador construye antes de detener la versión actual, respalda los datos y comprueba la revisión nueva. Conserva configuración, cuentas y backups. `axon rollback --wait` vuelve al código anterior manteniendo los datos actuales.

Para instalaciones Compose, conservá `.env` y `data/`, obtené esta publicación y reconstruí únicamente AXON. Recargá el navegador para cargar la interfaz nueva.
