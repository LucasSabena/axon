# Auditoría de bugs — 2026-10-06

18 subagentes en paralelo auditando todo el repo (backend TS, helpers Python, frontend JS, build/deploy). ~290 hallazgos brutos, ~280 únicos tras deduplicar (varios bugs fueron confirmados por 2-3 agentes independientes). Detalle de verificación en el historial de la sesión.

## CRITICAL

- **`src/storage/force-delete-host.py:37` + `src/file-operations.ts:237` — bypass total del denylist vía symlinks intermedios → borrado arbitrario como root.** `os.open(parent, O_NOFOLLOW)` solo protege el último componente; los intermedios se resuelven con symlinks. `ln -s / /tmp/evil` + `paths:["/tmp/evil/etc/ssl"]` borra `/etc/ssl` como root. Plantable vía `tar -xf` de `/api/files/archive`. *Confirmado por 2 agentes.* Fix: `anchor()` fd-relative por componente (como trash-host.py) o realpath + re-validar checks.
- **`src/storage/force-delete-host.py:5-6` — denylist incompleto aun sin symlinks.** `/root/.ssh`, `/home/<otro>`, `/var/lib/postgresql`, `/usr/local`, `/opt`, `/snap`, `/lib32` son borrables como root. Fix: allowlist (HOME + raíces de volúmenes) en vez de denylist.

## HIGH

- **`src/index.ts:1210` — proxy `/p/:port/` reenvía `Cookie` (incl. `axon_session`) a servicios arbitrarios en loopback.** Cualquier app proxied recibe el token admin de 7 días, replayable contra toda la API. Strip `axon_session`/`authorization` antes de forwardear.
- **`public/app.js:865` — XSS almacenado vía `data-id="${p.id}"` sin escapar.** `POST /api/projects` acepta `body.id` sin validar (`src/index.ts:763`) → payload persistente que ejecuta en cada sesión. Escapar + validar id server-side.
- **`public/navigation.js:21` + `interaction.js:92` — `crypto.randomUUID()` solo existe en secure contexts.** En `http://192.168.x.x/` el panel queda innavegable por completo. Fallback a `Math.random`.
- **`public/app-migrations.js:11-18` — "Confirmar retirada" aplica el plan equivocado.** Los botones no llevan plan id; el handler usa el global `retirementPlan` → si preparaste otro plan después, la acción destructiva cae sobre el servicio incorrecto.
- **`src/agents.ts:2204` — `setSetting` permite que un scalar sobrescriba secciones enteras.** `MANAGED_KEYS` omite `context_servers`, `env` (credenciales Claude), `permissions`, `hooks`, `model_list`… → `POST {key:'env', value:'x'}` borra los tokens.
- **`src/agents.ts:1894` — `toggleSkill` renombra archivos dentro del destino de un symlink.** Deshabilita el skill para todos los agentes y la fuente del CLI. Rechazar cuando `lstat` es symlink.
- **`src/library.ts:1885` — `/api/library/trash` siempre falla silenciosamente.** El request interno a `/api/files/trash` no manda `origin` → 403; la respuesta reporta `ok:true, removed:0` y la UI celebra. Agregar header `origin` como hace `ctx.trash` (l.1644).
- **`src/library.ts:1057 + 301` — shares rotos para paths con componente symlink.** `canonicalSharePaths` guarda realpath; `resolveInRoots` valida contra raíces *sin* resolver → archivos desaparecen de shares, `/f`, `/zip` 404.
- **`src/ports.ts:661` + `src/projects.ts:262` — `stopProject` mata por PID persistido sin verificar identidad.** PID reciclado post-restart (ej. `sshd`, `dockerd`) recibe SIGKILL como root. *Confirmado por 2 agentes.* Verificar `starttime`/`cwd` antes de kill.
- **`src/cloud/dropbox.ts:182` — `finishUpload` envía `content_hash` de un buffer vacío.** Todo upload no-vacío es rechazado por Dropbox (`content_hash_mismatch`). Pasar el hash real u omitirlo.
- **`src/platform/backups.ts:143` — `id` duplicado en destinations → segundo disco nunca recibe backups.** Dedup de `enqueue` por `destinationId` y schedule key colisionan → pérdida silenciosa de protección.
- **`src/platform/desktop-host.py:108` — x11vnc `-nopw` + websockify sin auth en localhost.** Cualquier proceso local/servicio con SSRF puede inyectar teclas en la sesión física (mirror mode `:0`). Agregar `-rfbauth` o unix socket.
- **`src/storage/file-task-host.py:56 vs 372` — cap de 8 MiB en `read_json` vs snapshot ilimitado (~300k filas).** Árboles de >25-40k entradas quedan `planned` para siempre.
- **`package.json:27` — build de `dist/` roto en 3 puntos** *(confirmado por 2 agentes)*: `transcribe_worker.py` no se copia (transcripción muerta, ENOENT); `versions-host.py` y `file-task-host.py` se copian a `dist/storage/` pero el bundle los lee en `dist/` (fallos silenciosos en scans/cleaner).
- **`deployment/axon.py:99` + `src/agent-accounts.ts:15` — `AXON_AGENT_PYTHON` se instala pero nunca se consume.** `setup-agents` crea un venv con `websockets` que nada usa → `enable-server` de Codex crashea con `ModuleNotFoundError`.
- **`src/alerts.ts:240-307` — flap de alertas: probe que falla ≡ "todo recuperado".** Un hiccup de dbus/docker/smartctl marca todo recuperado, limpia cooldowns y re-dispara notificaciones al siguiente tick.

## Patrones sistémicos (mismo bug, varios archivos)

1. **Subprocess timeout mata solo el wrapper** — `nsenter`/`runuser` muere, el proceso host queda huérfano. `host.ts:60`, `storage/host-argv.ts:17`, backups.ts, transcribe. Fix común: process-group kill o `timeout(1)` del lado host.
2. **`x ||= readFile(...)` cachea promesas rechazadas** → fallo transitorio = 503 eterno. platform/backups.ts, platform/desktop.ts, agent-accounts/usage/consumption/context.ts.
3. **Polls sin timeout** → locks/jobs eternos: transfer-review.js, file-operations runPurge, jobs.ts, watchJob, mozjpeg worker (sin `onerror` path).
4. **GET con side-effects**: `GET /api/storage/plans/:id` muta estado del worker; `GET /x/hook/:token` ejecuta scripts; `GET /pair?t=` mintea sesión.
5. **Sin GC de directorios de operación** → caps que bloquean permanentemente: `~/.local/share/axon/operations` (200), compose-release checkpoints (20), releases/backups del installer.
6. **Snapshots stale / mount-identity**: mount table leída una vez (force-delete), `running.pid` persistido, drops.json confiado al boot.
7. **Docker ausente/wedged**: sin timeout + sin fallback en varios paths → hangs de HTTP y caches de promesas colgadas.
8. **Body caps inconsistentes**: `protect()` solo cubre algunos módulos; agents/ops/docker aceptan bodies arbitrarios.
